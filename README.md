# u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209

A program that writes one short text for make.fun's bounty `u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209`: the single line an agent would post about its human on a rating site, stored in `main.py` as one string constant and written as UTF-8 bytes with no trailing newline to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (falling back to `/output`), printing the character count to stderr.
